# Ohjaus

Miten pelaaja ohjaa peliä näppäimistöllä, hiirellä, peliohjaimella tai kosketusnäytöllä.

| Ohje | Sisältö |
| --- | --- |
| [Ohjainten lisääminen](ohjainten-lisays.md) | Näppäimistön, hiiren, peliohjaimen ja kosketusnäytön kuuntelu `Listen`-aliohjelmalla. |
| [Ohjainten ryhmittely](ryhmittely.md) | Näppäimet toimivat vain tietyssä pelitilassa, esimerkiksi valikossa. |
| [Tähtäys](tahtays.md) | Aseen suuntaaminen hiirellä tai ohjaimen tatilla. |
| [Värinä](varina.md) | Peliohjaimen tai puhelimen värinä. |

Katso myös [Olioiden liikuttelu ja siirtely](../oliot/liikuttelu.md) (Oliot-osiossa),
opas [Kahden pelaajan tasohyppely](kaksi-pelaajaa.md) ja
[Mihin koodi kirjoitetaan](../ohjelmointi/mihin-koodi-kirjoitetaan.md), jos
näppäimen käsittelijä tarvitsee oliota toisesta aliohjelmasta.
